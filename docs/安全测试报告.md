# 安全测试报告

> 版本：v0.4.1（沙箱核心 v0.4.0 起默认注入）
> 范围：编译期逃逸拦截（E0063-E0066）与运行时沙箱兜底（`_FlySandbox`/`_fly_*`）的全部测试与对抗验证

## 1. 测试目标

沙箱的威胁模型是**双层防线**：

| 层 | 位置 | 机制 | 拦截对象 |
| :--- | :--- | :--- | :--- |
| 编译期 | `internal/checker/escape.go` | 静态遍历 AST | 危险内建调用/别名、反射属性链、`__builtins__`、危险模块导入 |
| 运行时 | `internal/runtime/fly_runtime.py` sandbox 节 | 内建代理 + `_fly_*` 护栏 + 受限 `__import__` | 动态下标反射名、转义变体、白名单外模块 |

两层名单必须完全一致（AGENTS.md 约定），由 `go test` 自动回归锁定（见 §5）。

## 7. 测试中发现并修复的真实缺口（v0.4.1）

### 缺口 1：运行时 import 白名单兜底从未生效

**现象**：`import tkinter`（白名单外）编译期放行后，生成的 `.py` 输出裸 `import tkinter`，绕过 `_fly_sb_import` 白名单检查，模块成功加载。

**根因**：`gen.go` 对 `ImportStmt`/`FromImportStmt` 原样透传 Python 语法，未接入 sandbox 节的受限导入。

**修复**：所有非 only 块 import 改为沙箱代理形式：

```python
# import math            → math = _fly_sb_import("math")
# import os.path as p    → p = _fly_sb_import("os.path")
# from math import sqrt as sq → _fly_sb_mod_math = _fly_sb_import("math", fromlist=("sqrt",))
#                               sq = _fly_sb_mod_math.sqrt
```

修复后 `import tkinter` 运行时报 `FlyRuntimeError: 沙箱: 模块 tkinter 不在白名单`；白名单模块（math/json/…）与别名、`import a.b` 根名绑定语义均验证正常。该行为由 `TestSandboxEscape/whiteout_mod`、`allow_mod` 锁定。

### 缺口 2：编译期字面量下标反射拦截从未生效

**现象**：`d["__class__"]` 编译期检查通过（错误地），仅靠运行时 `_fly_get` 兜底。

**根因**：lexer 的字符串 token 保留原文（含引号，gen 需要），而 `escape.go` 直接用 `StringLit.Value` 与反射名单比对（`"\"__class__\""` ≠ `"__class__"`），比对恒 false。

**修复**：`escape.go` 新增 `strValue()` 剥离前缀与引号（含三引号）；转义变体（如 `"\u005f_class__"`）编译期无法解码，明确由运行时兜底。修复后 `escape_subscript.fly` 编译期报 E0064 ×3，`TestSandboxEscape/escape_unicode_key` 验证转义变体的运行时兜底。

## 8. 已知限制（设计内）

1. **CPython 顶层帧缓存 builtins**：模块顶层 `f_builtins` 指向真实 builtins，运行时代理只在函数/类体内生效——顶层逃逸依赖编译期拦截（危险内建名**任何读取位置**都报 E0063，含 `def eval` 遮蔽，保守策略）。
2. **转义变体**：`"\u005f_class__"` 等字符串转义构造的反射名编译期不可解码，由运行时兜底。
3. **`only` 块语义优先**：only 块内白名单外访问报 E0045（only 白名单），不重复报 E0066。
4. **静态可确定的 import 全部编译期拦截**；运行时 `_fly_sb_import` 主要兜底名单漂移与动态场景。

