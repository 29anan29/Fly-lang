# Fly-Lang 报错清单

所有编译错误统一格式：`error: <文件>.fly:<行>:<列>: <消息>`（`fly check` 与 LSP 诊断同一管线）。
以下按关键字/阶段整理全部错误消息，`%s`/`%d` 为占位符。

## 词法/语法错误（parser）

| 消息 | 说明 |
| :--- | :--- |
| 期望 %s，实际为 %s | 语法结构不匹配（如 `期望 :`、`期望 标识符`） |
| 期望表达式，实际为 %q | 表达式位置出现非表达式 |
| 期望语句结束，实际为 %q | 语句后出现多余内容 |
| 关键字 %s 暂不支持 | `with` 等未实现关键字 |
| 关键字参数名必须是标识符 | `f(**1)` 类非法调用 |
| 非法赋值目标 | `1 = x` 类非法左值 |
| 装饰器后必须跟随 def 或 class | `@deco` 后接非定义 |
| 字典/集合推导式暂不支持 | `{k: v for ...}` |
| 字典解包 {} 暂不支持 | `{**d}` |

## safe/mask 污点（checker/taint.go）

| 消息 | 说明 |
| :--- | :--- |
| 未净化的外部输入 %s 流入 %s（危险汇点） | `safe x` 声明的污点变量未清洗即流入 eval/exec/os.system/subprocess/SQL |
| 敏感数据 %s 不可流入 %s（输出上下文） | `mask x` 变量流入 print/logging/f-string 输出 |

## lock（checker/lock.go）

| 消息 | 说明 |
| :--- | :--- |
| lock 变量 %s 不可再赋值 | 常量二次赋值/复合赋值 |
| lock 变量 %s 不可删除 | `del` 常量 |
| lock 变量 %s 不可通过 %s() 反射读取 | `globals()`/`vars()` 读取 |
| lock 变量 %s 不可通过反射修改 | 下标/属性反射路径修改 |
| lock 变量 %s 不可通过 setattr 修改 | `setattr` 篡改 |
| lock 变量 %s 未定义 | `lock` 引用不存在的名字 |

## guard（checker/guard.go）

| 消息 | 说明 |
| :--- | :--- |
| guard 变量 %s 未定义 | guard 的对象在作用域中不存在 |
| guard 类型必须是简单类型名（如 int、str） | 类型位置出现复杂表达式 |
| guard 类型 %s 与参数注解 %s 不一致 | 函数参数注解与 guard 类型冲突 |
| guard 条件中引用了未定义的名字 %s | 条件内引用了未知变量 |
| guard 至少需要一个类型或条件 | 空 guard |

## only / seal / trace（checker/only.go）

| 消息 | 说明 |
| :--- | :--- |
| only 块禁止访问 %s（不在白名单 %v） | only 块内使用 os/subprocess/eval 等黑名单名字 |
| only 白名单不能为空 | `only ()` |
| seal 类实例 %s 的属性 %s 不可修改 | seal 类实例属性赋值/删除（编译期静态识别） |
| seal 后必须跟随 class 定义 | `seal def` 等 |
| trace 级别 %s 非法 | 仅 DEBUG/INFO/WARNING/ERROR/CRITICAL |
| trace 参数 %s 未知 | 仅 level/args/ret |
| trace 块内函数名/参数名 %s 不能以 _fly_ 开头 | `_fly_` 为保留前缀 |

## cage（parser，单位换算期）

| 消息 | 说明 |
| :--- | :--- |
| cage 参数 %s 必须是字符串 | `max_time="5s"` 形式 |
| max_time 格式非法：%q | 仅 500ms/5s/2m/1h（含纯数字=秒） |
| max_memory 格式非法：%q | 仅 B/KB/MB/GB（含 iB） |
| cage 参数 %s 未知 | 仅 max_time/max_memory |
| cage 需至少指定 max_time 或 max_memory 之一 | 空 cage |

## 运行时异常（注入的 .py 运行时）

| 异常 | 说明 |
| :--- | :--- |
| GuardError | guard 断言失败 |
| ResourceExhaustedError | cage 内存超限（MemoryError 转换） |
| TimeoutError | cage 执行超时（SIGALRM） |
| AttributeError | seal 类实例属性增删改 |
| RuntimeError（only: 禁止访问...） | only 白名单代理拦截动态名称 |
