# Fly-Lang 报错清单

所有编译错误统一 Rust 风格格式（`fly check` 与 LSP 诊断同一管线，LSP `code` 字段同码）：

```text
error[E0031]: 污点数据流入危险汇点
  --> app.fly:10:23
   |
  10 |     obj = pickle.loads(data)
   |                       ^^^^^^
   |
   = help: 未净化的外部输入 data 流入 pickle.loads（危险汇点）。对该值先做净化（白名单/类型校验）再流入汇点，或改用 only 白名单约束
   = note: SECURITY.md 污点分析一节
```

错误码为 `E0001` 起连续编号（新增错误接续排号，不做类别分段）。每个错误码在 `internal/ast/errors.go` 登记：标题、修复建议（`help`）、文档链接（`note`）与示例报错；运行时可用 `fly error E0031` 直接查询。

## 运行时异常（注入的 .py 运行时）

| 异常 | 说明 |
| :--- | :--- |
| GuardError | guard 断言失败 |
| ResourceExhaustedError | cage 内存超限（MemoryError 转换） |
| TimeoutError | cage 执行超时（SIGALRM） |
| AttributeError | seal 类实例属性增删改 |
| RuntimeError（only: 禁止访问...） | only 白名单代理拦截动态名称 |
| FlyRuntimeError | 动态错误兜底：`src:行:列: 描述`（除零/越界/KeyError/属性缺失/类型转换/不可迭代等，不再裸抛 Python 异常） |
| FlyRuntimeError（沙箱: ...） | 运行时沙箱拦截：反射链（`__class__`/`__bases__`/`__subclasses__`/`__dict__` 等属性与下标）、危险内建名访问（eval/exec/open/getattr/globals/vars 等）、危险模块导入（os/subprocess/sys/pickle 等） |

## 沙箱（所有编译产物默认注入）

生成的 .py 以 `_FlySandbox` 内建代理 + `_fly_attr`/`_fly_get`/`_fly_set` 反射黑名单 + 受限 `__import__` 运行：

- 编译期（E0063-E0066）拦截静态逃逸：危险内建调用/别名、反射属性链、`__builtins__` 访问、危险模块导入
- 运行时兜底拦截动态逃逸：变量下标反射名（`k = "__class__"; x[k]`）、函数内危险内建名访问
- 模块顶层帧缓存 builtins（CPython 架构限制），顶层逃逸依赖编译期拦截；函数体/类体内由运行时代理生效
- 白名单模块（math/json/time/re/random 等）正常导入；`only` 块内仍为严格白名单代理

未检查的边界：`from x import *` 后放行全部名字；only 块内名字访问由白名单检查负责；动态场景（用户输入、反射、条件分支内赋值）由运行时兜底覆盖。
