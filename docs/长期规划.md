# Fly-Lang 长期规划：让语言自己成体系

> 状态：草案 / 待评审
> 配套文档：[../Plan.md](../Plan.md)（P0-P6 实现方案）、[Rust迁移方案.md](Rust迁移方案.md)（R0-R5）、[../方案.md](../方案.md)（语言设计）
> 阶段编号沿用既有体系：P（Go 实现）、R（Rust 迁移），本文档新增 L（Long-term，生态与成体系）

## 1. 愿景

Fly 不止是一门"能编译的 Python 安全超集"，而是一个**自洽、自养、自举**的体系：

- **自洽**：编译期检查、错误格式、发布渠道、编辑器支持，全部同一套契约，无历史包袱
- **自养**：每个环节（测试→CI→发布→升级→插件）全自动，维护者只需打 tag
- **自举**：语言工具链用这门语言自己编写——先用 Fly 写 fmt/doc/test，最终写编译器组件，双实现互证正确性

## 3. 成体系的四大支柱

### 3.1 自举（Self-Hosting）——核心

转译器存在"鸡生蛋"问题（Fly 写编译器需要先有编译器），务实路径是**分级自举**：

| 层级 | 内容 | 语言 | 意义 |
| :- | :--- | :--- | :--- |
| L1 工具自举 | fly fmt / fly doc / fly test | **Fly** | 工具链本体是 Fly 程序，自己跑在自己之上 |
| L2 后端自举 | 代码生成器（AST→Python 发射器）用 Fly 重写 | **Fly** | 编译器最"机械"的部分换皮验证 |
| L3 前端自举 | lexer/parser/checker 用 Fly 实现 | **Fly** | 完整参考实现；与 Rust 主实现双轨互证 |
| 引导链 | 自举版编译器的产物由 Rust 版 `fly build` 编译 | 混合 | 每次升级后自举版可自编译自己（`fly build flyc.fly` 产出 flyc.py 再编译 flyc.py） |

原则：
- **双实现互证**：Rust（主实现，性能/分发）+ Fly（参考实现，可读性/正确性），golden 输出逐字节对比是自举期的"裁判"
- 自举组件先做**可编译**（P0 子集 + 自带库），不做一次性大爆炸
- 自举版编译器不取代 Rust 版——Rust 版是分发物，Fly 版是体系自证

### 3.2 生态（Packages & Stdlib）

| 组件 | 方案 | 决策点 |
| :--- | :--- | :--- |
| 标准库 | `internal/runtime/fly_runtime.py`（go:embed）扩展为 `flyx` 包：审计日志、密码哈希、沙箱工具、污点源/汇点常量表 | D-3 内置 vs 独立包 |
| 包管理 | **复用 PyPI**：Fly 源码发布为 `.fly` 源码包 + 编译产物，`fly pkg add` 内部走 pip/venv，`fly build` 时按包内 `fly.toml` 声明注入 | D-2 复用 vs 自建 registry |
| 元数据 | `fly.toml`：name/version/deps/安全策略（默认锁 8 关键字约束） | — |
| 示例库 | example/ 两个 FlyToDos（Web + PyQt6）作为模板，扩展 CLI 模板 | — |

### 3.3 质量（Quality）

| 层 | 手段 |
| :--- | :--- |
| 单测 | lexer/parser 节点级表驱动（已有） |
| golden | 全量输出快照对比（P6 补全）；自举期 Rust vs Fly 双实现 diff |
| 反例 | `# fly:error` 表驱动（已有框架，P1-P4 扩充） |
| fuzz | Go 原生 fuzz 测 lexer/parser 崩溃与挂起（R 版用 cargo-fuzz） |
| 行为 | 生成 .py 用 Python 3.10+ 实跑（CI 矩阵 linux/macos/windows） |
| 差分 | `scripts/diff_golden.sh`：Rust vs Fly 自举版输出逐字节比对 |

### 3.4 治理（Governance）

- **RFC 流程**：`docs/rfcs/`，任何语言语法/关键字/工具链改动先提 RFC（模板含动机/语义/反例/迁移）
- **版本策略**：SemVer + dev/release 双渠道（已实现）；`tools/release.sh` 一键发布（已实现）；CHANGELOG 从 conventional commits 自动生成
- **安全**：SECURITY.md（已有）+ 漏洞报告私信；`guard`/`mask`/`cage` 落地后做安全自检清单
- **社区**：CONTRIBUTING（已有）、good-first-issue 标签、示例/教程仓库
- **文档站**：GitHub Pages 或 docsify（D-5），README 自动同步

## 4. 阶段路线图

### L0 收尾与基线（当前 → v0.3.0）

- P1-P4 全部关键字落地（lock/guard → safe/mask → only/seal/trace → cage/runtime）
- P6：golden 全量覆盖、错误消息快照、边界用例（闭包/嵌套/f-string 内 mask）
- 行为测试接入 CI（python3 实跑）
- 验收：`方案.md` 全部 8 个示例正反例通过；`go test ./... && go vet ./...` 全绿

### L1 Rust 迁移（→ v1.0.0）

- 按 [Rust迁移方案.md](Rust迁移方案.md) R0-R5 执行；R5 时打 v1.0.0 并退役 Go 版
- 迁移完成后 `fly` 为单静态二进制（<3MB），插件/CI/update 契约零改动
- 验收：golden 与 Go 版逐字节一致；v1.0.0 产物与 v0.2.1 同构

### L2 工具链（Fly 自写工具）

- `fly fmt`：AST 驱动格式化（注释保留）；**用 Fly 编写**，Rust 版通过 FFI 或子进程调用（D-4）
- `fly doc`：docstring → Markdown 文档生成器，**用 Fly 编写**
- `fly test`：目录级测试运行器（`fly test ./tests`），断言库内置
- `fly pkg init/add/build`：包骨架/依赖/编译
- 验收：`fly fmt` 格式化自身源码后 golden 无差异（dogfooding 自证）

### L3 标准库与包生态

- `flyx` 标准库发布（审计/哈希/沙箱/安全常量表）
- `fly pkg` 打通 PyPI 复用路径；第一个第三方包（如 `flyx-http`）发布
- 编辑器矩阵：Neovim（LSP 客户端配置）、JetBrains（LSP 通用协议）
- 验收：`fly pkg add` 安装依赖并编译运行示例

### L4 自举里程碑

- 编译器后端（gen 发射器）用 Fly 重写，golden 与 Rust 版 diff 全绿
- 前端（lexer/parser）用 Fly 实现 `flyc.fly`，自编译闭环：
  `fly build flyc.fly → flyc.py → python3 flyc.py（编译任意 .fly）`
- 验收：Fly 写的编译器能编译 FlyToDos 并产出可运行 .py

### L5 开放生态

- RFC 流程上线、CHANGELOG 自动生成、文档站部署、playground（Web 端 `fly lsp`/`CheckSource` 服务）
- 安全评审清单 + 漏洞披露流程
- 验收：外部贡献者提交 PR 全流程无维护者人工干预

## 5. 关键决策点

| # | 决策 | 建议（默认） | 备选 |
| :- | :--- | :--- | :--- |
| D-1 | 自举地位 | Fly 版编译器为**参考实现**（双实现互证），Rust 版保持分发物 | Fly 版替代 Rust 版（性能不达标，不推荐） |
| D-2 | 包生态 | **复用 PyPI/pip**（Python 超集天然兼容，生态即资产） | 自建 registry（成本高，无先发优势） |
| D-3 | 标准库形态 | `flyx` 独立包（`fly pkg add flyx`），runtime 保持最小内置 | 全内置（污染命名空间） |
| D-4 | 工具语言 | **用 Fly 写 fmt/doc/test**（自举优先），Rust 壳调用 | 全 Rust（快但放弃自举） |
| D-5 | 文档站 | GitHub Pages + docsify（零成本） | 自建（维护成本） |
| D-6 | 自举编译器运行形态 | 编译为 .py 由 python3 跑（无自举引导问题） | 编译为原生（需要自举引导，复杂） |

## 6. 风险

| 风险 | 等级 | 缓解 |
| :--- | :--- | :--- |
| P1-P4 关键字语义落地拖延 | 高 | 每个关键字独立验收（Plan.md 已拆分）；文档示例即验收 |
| Rust 迁移与生态并行冲突 | 中 | 阶段串行：L1 完成前不做 L2+（工具链在 Rust 版上建立） |
| 自举版漂移 | 中 | golden diff 脚本 + 双实现互证；自举版只做参考 |
| 生态冷启动（无人写包） | 低 | 示例库 + 模板 + 文档站先行 |
| 单人维护精力 | 低 | 全自动 CI/发布已就绪；RFC 流程降低决策成本 |
